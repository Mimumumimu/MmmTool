# 0020 添付の一時フォルダを、別ビルドと共有する

## 状況
元がファイルではない添付 (貼り付けた画像など)は、`%TEMP%\MmmTool\session_日時\` に一時保存する (SDK の `AttachmentStore`)。以前は、EXE のパスのハッシュで一時フォルダを分けていた。

## 決定
- 一時フォルダは、Debug / Release など別の場所の EXE と共有する (EXE のパスのハッシュで分けない)
- 古いものの掃除では、同時に動いている別ビルドの、1 日より古いセッションも消える (ユーザーの決定。意図した仕様)
- レビューで「別ビルドのフォルダを消しうる」と指摘・提案しない

## 理由
添付は CLI が読み込めば用済みの一時ファイル。元は、読み込んだらすぐ消す仕様だったものを、緩めて残しているだけ。ハッシュの段は、送るパスを長くするだけで、守る価値が無い。

## 影響
SDK の `CLAUDE.md` と `docs/controls.md` にも同じことを書いている。

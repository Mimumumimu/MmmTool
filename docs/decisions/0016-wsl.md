# 0016: CLI補助を WSL でも動かす（シェル自体を WSL にする）

## 背景
WSL に入れた Claude Code も、CLI補助から使いたい。WSL の中の CLI には、Windows のパス（`D:\work\a.txt`）を渡しても読めないので、作業ディレクトリの移動・添付ファイルのパスを、WSL から見たパス（`/mnt/d/work/a.txt`）にして渡す必要がある。また、今どちらの環境で動いているかを、どこかで 1 つに決めて持つ必要がある。

## 決定
- ターミナルのシェル自体を WSL（`wsl.exe`。既定のディストリビューションの既定のシェル）にする（ユーザーの決定）。PowerShell のまま `wsl claude` で起動する形にはしない
  - シェルのコマンド（cd・`claude update` など）も、すべて Linux 側で動く。どちらで動いているかはターミナルのシェルの種類（SDK の `ShellKind.Wsl`）で決まり、途中で混ざらない（PowerShell の中で `wsl claude` を起動する形だと、起動したものが WSL かどうかを、コマンドごとに覚えておく仕組みが要る）
  - 起動時の作業ディレクトリは、Windows のパスのまま渡せば、wsl.exe が Linux のパスに変換する
- どちらの環境かは、定型コマンドのファイル（`Data/CliCommands.json`）の `environment`（`"windows"` / `"wsl"`）に持つ（ユーザーの決定）。定型コマンドは、その環境向けに書かれたものなので、まとめて持つ。ファイルを新しく作るとき（無い・壊れていた）に、ダイアログで選ぶ。変えるときは、CLI補助の左ペインの「⋯」メニューの「定型コマンドを初期化…」で、既定の内容に作り直して選び直す（今の内容は引き継がない。ターミナルはいつも起動し直す。ユーザーの決定）
- パスの変換は SDK に置く（`WslPath`・`ShellCommands.TryConvertPath`）。文字列だけで変換し、wslpath は呼ばない（パスごとに WSL のプロセスを起動すると遅いため）
  - UI（作業ディレクトリ変更ダイアログ・添付の一覧）は Windows のパスのまま扱い、シェルへ渡すときだけ変換する
- 貼り付けた画像の一時保存先は、WSL の /tmp（`\\wsl.localhost\<ディストリビューション名>\tmp\MmmTool\`。CLI へは `/tmp/MmmTool/...` で渡す）にする（ユーザーの決定）
  - 終了時の削除・古い一時フォルダの掃除はしない（ユーザーの決定）。WSL の /tmp は、systemd が有効なら WSL の起動のたびに空になるため。送信前に × で取り除いた画像は、Windows と同じくすぐ消す（それ以降使わないことがはっきりしているため）
  - Windows の環境では、これまでどおり `%TEMP%\MmmTool\` に置き、終了時に消す（環境ごとに 1 つずつ一時保存先を持つ。SDK の `AttachmentStore` / `AttachmentStore.ForWsl`）
- 会話履歴の削除の補助スクリプトは、WSL 用を Python 3 で別に作る（`Assets/Tools/Remove-ClaudeSession.py`。ユーザーの依頼）。操作・画面の流れは PowerShell 版と同じにする
  - PowerShell 版を WSL の履歴（`\\wsl.localhost\...`）に向けると、ネットワークのパスなので Windows のごみ箱に入らず、戻せない形で消えてしまう。WSL 側で、Linux の標準のごみ箱（freedesktop.org の Trash。`~/.local/share/Trash`）へ移す
  - Python 3 にしたのは、Ubuntu に標準で入っていて、JSON の読み込みとキー入力の処理を、追加の道具（jq など）なしで書けるため。bash だけでは JSON を確実に読めない

## 制約（実機での確認待ち）
- 制約: 作業した時点で、ユーザーの PC に WSL の Claude Code がまだ無く、WSL での動作（シェルの起動・cd・添付のパス・/tmp への保存・削除スクリプト）は確かめられていない。WSL の環境ができたら、VS で確かめる
- 制約: ドライブの割り当て先は WSL の既定の `/mnt/` とする。`/etc/wsl.conf` の `[automount] root` を変えた環境では、違うパスになる（この値は WSL の中からしか読めない）

# 0004 トレイは Win32 を直接呼び、メニューはオーナードローにする

## 状況
タスクトレイに常駐し、右クリックでリンクやリマインダーのメニューを出したい。

## 決定
- `Shell_NotifyIcon` を直接 P/Invoke する。WinForms の `NotifyIcon` / `ContextMenuStrip` は使わない
- メニューは Win32 のポップアップメニューを使い、項目はオーナードローで描く (SDK の `TrayMenuRenderer`)

## 理由
- WinForms に依存せず、WinUI 3 のアプリに別の UI 基盤を混ぜない
- 標準のメニューは、文字の大きさ・色を変えられない。ダーク / ライトの切り替えや、日本語に合うフォントのために、描画を自分で持つ

## 影響
メニューの見た目 (フォント・配色・余白・矢印・枠)は自分で面倒を見る (詳細は `specs/tray-and-main.md`)。枠 (外周・影)は Windows が描くので、uxtheme の非公開序数でシステムのダーク設定に従わせている。非公開の仕組みに頼るため、動かない環境ではライトのままになる。

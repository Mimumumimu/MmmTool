# ノート

開始日から終了日までの期間を決めて、タイトルと本文を書き、その日に有効なノートを日ごとに 1 枚の画面へ並べて読む機能。複数人では連絡事項、1 人ではナレッジの書き足しに使う。サイドバーのページ「ノート」だけを持つ。`src/Plugins/MmmTool.Notes/`(Core 側は `src/Plugins/MmmTool.Notes.Core/`)。

## 位置づけ
- 日付が主役の読み物。「今日出すべきものを全部、1 枚で読める」ことが目的で、1 件ずつ選んで読む画面にしない (一覧と本文の 2 列にしない)
- 保存先は、ローカルモードが SQLite、DB モードが SQL Server。表は `Note` の 1 つ ([database.md](database.md))
- 検索は持たない (探し方は、そのうち。[../todo.md](../todo.md))
- 返信 (スレッド形式)を持たない。会話の機能は Teams などの役割で、ノートは「その日に有効なものを 1 枚で読む」ことに絞るため。ノートの履歴 (変更の記録)も持たない
- 外部への通信を持たない。表示するページは、外部の資源を読み込まず、スクリプトを実行しない (MmmTool に外部送信の処理を入れない決まりのため)
- 画面の文言は仮 (「この日のノートはありません」・ボタンやチェックの名前など)

## データ
- 1 件のノートの持ち物は、書いた人・公開範囲・開始日・終了日・重要度・タイトル・本文
- 開始日は必須。終了日は空にできる (空は無期限。`9999-12-31` で保存する)。終了日が空のノートは、開始日以降の毎日出る
- 重要度は 5 段階 (最低・低・中・高・最高)。新規の初期値は「中」。固定表示 (ピン留め)の 1 つの印にしない (最重要のものを、確実に上へ出す段階が要るため)
- 公開範囲は「全員」か「自分だけ」(DB モードだけ。ローカルモードは 1 人なので、画面に出さない)。新規の初期値は「全員」。変えられるのは書いた人だけ (ほかの人が、全員に見えるノートを、自分だけのものにして隠さないため)
- 本文は、書いたとおりの文字で保存する (表示のときだけ、整形・リンク化する)。保存するときに、タグの除去も、リンクの変換もしない
- タイトルは 100 字まで (`NoteLimits`が持ち、DB の列の長さと同じ。UTF-16 の 1 単位で数える)。本文は、上限を決めない (DB の列の最大まで。SQL Server の `nvarchar(max)` は約 2 GB、SQLite の `TEXT` は約 1 GB)。書く量を制限しないため
- 削除は論理削除 (`IsDeleted`)。復元はいつでもできる。DB では行を消さない

## 画面
入口はサイドバーのページ「ノート」だけ。上のバーと、その下のカード一覧からなる。

### 上のバー
| 部品 | 動き |
| --- | --- |
| 「新規」ボタン (見出しの右) | 入力のウィンドウを開く。表示を切り替える部品とは並べない |
| 前の日・日付の選択・次の日・「今日」 | 表示する日を決める。初期は今日。作業管理の入力日と同じ形 |
| 「タイトルだけ」のスイッチ | 全部のカードを同じ状態にする。オフが「全文」で、初期はオフ。本文の長さでは変わらない。スイッチの文字は、オンでもオフでも「タイトルだけ」に固定する (入り切りで文字を替えると、広いほうの幅が常に確保されて、右の部品との間が空き、今の状態も分かりにくくなるため) |
| 「削除したものも表示」のチェック | 入れると、削除済みのノートも、同じ並びに混ぜて出す。初期はオフ |

日付・切り替えを変えたときは、先頭から表示し直す。

### カード一覧
- ページ全体 (見出し・操作の行・カード)は、同じ幅 (約 1000px)の 1 本の列にして、中央に置く。複数の列に並べない (重要度の順に、上から下へ読むものなので、視線を横に動かさないため)。広い画面でも、操作の行の右端とカードの右端が揃い、「編集」「削除」がタイトルから遠くならない
- 表示する日に有効なもの (開始日 ≤ その日 ≤ 終了日)を、全部、縦に並べる。ノートの数が多くても、一覧は 1 枚の続きの画面で、ページを分けない
- 並びは、重要度の高い順。同じ重要度の中は、更新日時の新しい順 (同じなら番号の大きい順)
- 一覧の部分は、WebView2 の 1 枚の HTML のページ (`NoteCardsView`)。カードごとに WebView2 を作らない (件数ぶんのブラウザープロセスができるため)。ライトモードとダークモードのどちらでも読める見た目にし、テーマが変わったら作り直す
  - ページは、仮想ホスト `notes.mmmtool.invalid` の `index.html` として、アプリが返す (文字列で渡す方式は、渡せる量に上限があり、本文は上限を決めないため)。仮想ホスト以外へのリクエストは、すべて失敗で返し、ページに `Content-Security-Policy` を付けて、外部の資源を読み込ませない
  - ページのスクリプトは止める (アプリ側から実行する、読んでいる位置を取り出すスクリプトは動く)。ブラウザーとしての機能 (キー操作・ズーム・自動入力)も止める。右クリックのメニューは、標準のものを出さず、カードの上では「編集」「削除」(削除済みなら「復元」)に差し替える (どのカードの上かは、アプリ側から実行するスクリプトで、右クリックした位置から調べる)。選んだ文字があるときは「コピー」を出す。メニューは、WebView2 の標準のものが項目の文字の幅しかなく押しにくいため、アプリ (WinUI)の `MenuFlyout` で出す。「タイトルだけ」でカードを開く動きは `<details>` で、「編集」「削除」「復元」は、仮想ホストの内部リンク (`https://notes.mmmtool.invalid/action/<操作>/<番号>`)で受ける。ページの移動を `NavigationStarting` で横取りして、アプリが処理する。`index.html` 以外への移動は、取り消す
  - 作り直すとき (切り替え・読み直し・保存)は、読んでいる位置と開いているカードを、作り直す前に取り出して、保つ (日付・切り替えを変えたときは、保たない)
  - WebView2 は、SDK のターミナルと同じ保存先 (`AppEnvironment.WebView2Directory`)・同じ設定 (`WebView2Setup`)で作る (同じプロセスの WebView2 は、同じ保存先なら同じ設定が要るため。[SDK の terminal.md](../../external/MmmSdk/docs/terminal.md))。初期化できないとき (WebView2 ランタイムが無い)は、一覧の場所に理由を文字で出す
- 1 枚のカードの上の行に出すもの: タイトル・期間 (終了日が空のときは「開始日 ～」)・作成者・更新者 (どちらも DB モードだけ)・更新日時・印。重要度は、帯で示す
  - 1 行目に、矢印・タイトル・印を左から並べ、期間・作成者・更新者・更新日時は、同じ行の右端 (「編集」「削除」の左)に寄せる。縦スクロールを短くするため。幅が足りないときだけ、右寄せのまま次の行へ折り返す
  - カードの上下の余白と、カードの間は、8px に詰めている
  - カードの枠は、全重要度で、四辺に 1px を引く。「高」「最高」だけ、左の枠を 4px の帯にし、中身の左端は、ほかのカードと揃える
  - 印は、タイトルの右に出す (印のために行を増やさない。タイトルの左に置くと、印の有無でタイトルの左端がカードごとにずれるため)
  - 作成者は `AuthorUserId`、更新者は `UpdatedByUserId` から引く。表示だけに使い、検索・結合・索引には使わない。名前は、SQL で結合せず、必要な人だけを番号で引く (`IAppUserRepository.GetUsersByIdsAsync`)。更新者が作成者と同じときは、更新者を省く (編集が誰でもできるので、ほかの人が直したことが分かるようにするため)
  - 更新日が今日のノートには、印を付ける (表示する日ではなく、実際の今日)。人ごとの既読の記録は持たない (印のためだけに表を増やさないため)
  - 「自分だけ」のノートには、その印を付ける (DB モードだけ)。削除済みには「削除済み」の印を付ける
  - 重要度は、カードの左端の細い帯で示す。「最高」は赤、「高」は橙。「中」「低」「最低」は帯を付けない (静かに保ち、目立たせたいものだけを目立たせるため)
- カードの本文は、「本文の表示」の決まりで整形して出す。「タイトルだけ」のときは、本文を出さず、カードを押すと、そのカードだけが開く。「全文」のときも、カードを押すと、そのカードだけが畳める。どちらも、本文の長さでは、開く・畳むを分けない (長さで見た目がそろわなくなるため)。本文が空のカードだけは、開く先が無いので、開閉の矢印を出さない
- カードの操作は、上の行の右に置く。「編集」(入力のウィンドウを開く)・「削除」(確認のダイアログを出して、論理削除する)。削除済みのカードは、薄く出して、「編集」と「削除」の代わりに「復元」を置く (確認は出さない)
- 編集・削除・復元は、見える人なら誰でもできる (リマインダーと同じ。書いた人が削除したノートを、ほかの人も戻せるようにするため)。見えないノート (ほかの人の「自分だけ」)は、そもそも出ない。ほかの人が先に変えて、操作しようとしたノートが無かったときは、失敗を InfoBar に出して、読み直す
- 表示する日にノートが無いときは、空の画面に、その日付と「この日のノートはありません」を出す
- 読み込み・操作に失敗したとき (`DataFileException`)は、上のバーの下に InfoBar で出す。今の表示は変えない

### 入力のウィンドウ
新規と編集で同じウィンドウ (`NoteEditWindow`)を使う。閉じたウィンドウは再表示できないので、開くたびに作る。親の上にモーダルで出す。大きさは変えられる (本文を広く書けるように)。

| 項目 | 内容 |
| --- | --- |
| タイトル | 1 行。必須 |
| 本文 | 複数行。右クリックのメニュー (下の「右クリックの助け」)を持つ。ファイルのドロップを受ける。最低 8 行ぶんの高さがあり、ウィンドウの余った高さまで伸びる。長いときは、欄の中でスクロールする |
| 開始日 | 必須。新規の初期値は、ページが表示している日 |
| 終了日 | 空にできる (空は無期限。「クリア」ボタンで空にする)。新規の初期値は空 (無期限)。あとから日を入れて終わらせる |
| 重要度 | 「最低」「低」「中」「高」「最高」の 5 つを横に並べた選択 |
| 公開範囲 | 「自分だけに表示」のチェック (オフは全員に見える。2 択なのでチェックボックス)。DB モードだけ。書いた人以外は、押せない |

- 開始日を終了日より後にした、または終了日を開始日より前にしたときは、もう一方を同じ日に合わせる
- 保存できるのは、タイトルがあり、開始日が入っているとき
- 保存に失敗したとき (`DataFileException`・入力の誤り)は、ウィンドウを閉じず、理由を InfoBar で出す
- 保存したら、ページが表示している日にそのノートが入るかに関係なく、ページを読み直す
- タイトルと本文は、フォーカスが来たら IME をオンにする (日本語の入力が多いため)
- タイトルと本文の入力欄、カードの表示は、等幅のフォント (`BIZ UDGothic, MS Gothic, Consolas`。作業報告・日報メモと同じ) にする。全角 1 文字が半角 2 文字の幅に揃い、タグや字下げの桁が揃うため。入力欄 (`TextBox`)には、行の高さの指定が無いので、行間は狭いまま (日報メモと同じ)。カードは、CSS の `line-height` で行間を広げる

### 右クリックの助け
本文の入力欄で右クリックすると、メニューを出す。選ぶと、本文に HTML のタグが入る。タグを知らない人でも、書式を付けられるようにするため。

| 項目 | 範囲を選んでいるとき | 範囲を選んでいないとき |
| --- | --- | --- |
| 色 | 押すと、選んだ文字の直下に、1 枚のパネルが開く。系統 (灰色・赤・橙など)を横に、段階 (濃い〜薄い)を縦に並べた格子から選ぶ。選んだ文字を色のタグで囲む。「標準」を選ぶと、選んだ文字の色を外す | 押せない |
| 太字・斜体・下線・取消線 | 選んだ文字を、対応するタグで囲む | 押せない |
| リンクを追加 | 選んだ文字をリンク名にして、リンク先を入力するダイアログを出す | リンク名とリンク先を入力するダイアログを出す |

メニューには、切り取り・コピー・貼り付け・すべて選択も入れる (欄の標準のメニューを置き換えるため)。並びは、文字の装飾 (色・太字・斜体・下線・取消線。色は、重要な連絡を目立たせるのに使うので先頭)、リンクを追加、クリップボードの操作の 3 つのまとまり。

- リンク先には、URL かファイルのパスを入力する。ファイルのパスは、`file:` の形に直して入れる。リンク名を省くと、リンク先を表示する
- ファイルやフォルダーを本文の入力欄にドロップすると、カーソルの位置に、リンクが入る。リンク名はファイル (フォルダー)の名前で、複数をドロップしたときは、1 つずつ改行して並べる。右クリックの「リンクを追加」と、どちらでも入れられる
- 色のパレット (`NoteColorPalette`)は、11 系統 × 4 段階の 44 色。「黒」は置かず、「標準」を置く (ダークモードで見えなくなるため。「標準」はそのときのモードの標準の文字色)
  - 各色は、カードの背景 (ライト `#FFFFFF`・ダーク `#2B2B2B`)に対して、ライト・ダークのそれぞれで、本文の文字として読める明るさ (コントラスト比 4.5 以上)になるよう、計算で決める。段階は、濃いほど強い (ライトは 9.0・7.0・5.5・4.5、ダークは 4.8・6.5・8.5・11.0 の比)
  - 色は、ライトモードで読める色の値 (`color:#RRGGBB` の形)で本文に入る。表示のときに、ダークモードでは同じ系統の別の色へ差し替える。パレットに無い値を手で書いたときは、色を付けない (標準の色になる)

## 本文の表示
本文は、基本は普通の文章で、書いたとおりの改行で出す。HTML のタグを書くと、許可したタグだけが反映される。HTML を知らなくても使え、知っていれば工夫できる形にする。Markdown は使わない (記法を覚えなくても使える形にするため)。

整形 (`NoteBodyFormatter`)は、取り除く方式ではなく、組み立て直す方式。本文の文字を、すべて HTML の文字に直して出し、許可したタグに当たる部分だけを、アプリが決まった形のタグ (属性も、アプリが決めた形だけ)で出す。出力には、アプリが作ったタグしか入らない。HTML の除去用の部品 (AngleSharp を使うもの)を入れない (外部へ接続する型を含み、MmmTool に外部送信のコード・DLL を入れない決まりに反するため)。

### 反映するタグ
| タグ | 反映すること |
| --- | --- |
| `b` `strong` / `i` `em` / `u` / `s` | 太字 / 斜体 / 下線 / 取消線 |
| `br` | 改行 |
| `ul` `ol` `li` | 箇条書き |
| `span` | `style="color:#RRGGBB"` の指定だけ (パレットの色だけ。ほかの指定は捨てる) |
| `a` | `href` だけ。`href` は `http` `https` `file` のものに限り、ほかは `a` ごと取り除く。仮想ホスト (`notes.mmmtool.invalid`)も取り除く (本文に書いた `<a>` が、カードの操作の内部リンクになりすまして、ほかの人のノートの削除などを呼ばないため) |

- 上にないタグと属性は、表示のときに取り除く。取り除くのは、タグだけ (中の文字は残す)。`script` と `style` は、中身ごと取り除く。注釈も取り除く
- 外部の画像などの資源を読み込むタグ (`img` `iframe` `link` など)は、反映しない。ほかの人が書いた本文を、安全に表示するため
- 閉じていないタグは最後に閉じる。対応しない閉じタグは捨てる
- 箇条書きのタグのすぐ前後の改行は、空きにならないよう、出さない
- 本文のタグに見えない `<` (「1 < 2」など)は、文字として出す

### 自動リンク
本文の中の `http://` と `https://` で始まる文字を、表示のときに、リンクにする。保存した本文は変えない。

- URL の終わりは、半角の URL に使える文字が続くところまで。全角の文字・空白・改行で切る
- 末尾の `.` `,` `;` `:` `!` `?` `'` は、URL に含めない。`)` と `]` は、対応する開きが URL の中に無いときだけ含めない (`…/日本_(国)` の閉じ括弧は URL に含める)
- すでに `<a>` のタグで書いてあるものは、二重にしない
- ブラウザーのアドレスバーからコピーした日本語を含む URL は、日本語の部分が `%E6%97%A5…` の形に直って貼られる想定。この形は、最後までリンクになる。日本語のまま書いた URL は、全角の文字の手前までしかリンクにならないので、右クリックの「リンクを追加」で入れる
- ファイルのパス (`C:\…` `\\server\…`)は、自動ではリンクにしない (誤判定が多いため)

### リンクを押したとき
- `file:` のリンクは、ページには、仮想ホストの内部リンク (`https://notes.mmmtool.invalid/open?u=<file: の URL>`)に包んで出す。仮想ホストの https のページから `file:` へ移ろうとしても、WebView2 (Chromium)が、移動が始まる前に止めてしまい、アプリが横取りする `NavigationStarting` が来ないため。アプリが包みを解いて、ふつうのリンクと同じ判定に回す (下の、ページに出したリンクだけを開く決まりも同じ)
- ページの中では開かず、`IPathOpener` で開く。`file:` のリンクは、パスにして開く (フォルダーはエクスプローラーで開く)。開けなかったときは、InfoBar に出す
- 開くのは、今のページに出したリンク (`NoteLinks.CollectHrefs` が集める)だけ。ファイルをページに落としたときなど、ページに出していない移動は、開かない (落としたファイルが、実行ファイルのとき、動いてしまうため)
- 開くのは `http` `https` `file` だけ。ほかの種類 (独自のスキームなど)は、押しても開かない (ほかの人が書いた本文のリンクを押すため)。この絞り込みは、上の整形の段階でも行う
- Ctrl+クリック・中クリックも、同じ判定に回す (新しいウィンドウは開かない)

## 読み込みと反映
- ページは、表示する日の分 (有効なもの・見えるもの)を読む。全部のノートは読まない
- 見えるのは、公開範囲が「全員」のノートと、自分が書いた「自分だけ」のノート。読み書きの SQL は、すべて、この条件を持つ (見えないノートを、番号だけで操作させないため)
- ほかの人の更新は、表示している日の分を 1 分ごとに読み直して反映する。前回と内容が変わったときだけ、画面を作り直す。自分の保存や削除のあとは、すぐ読み直す
- 読み直しは、ページが見えている間だけ行う。ほかのページを見ている間 (`Unloaded`)と、メインウィンドウをトレイへ隠している間 (`XamlRoot.IsHostVisible` が false)は、DB に問い合わせない。見えるようになったら、すぐ読み直す
- ローカルモードは、書いた人が常に 1 人 (`Id = 1`)。公開範囲は使わない

## 保存
- ローカルモード: SQLite (`Data/MmmTool.db`)の `Note` 表 (`SqliteNoteRepository`)
- DB モード: SQL Server の `Note` 表 (`SqlServerNoteRepository`)。表がまだ無いときは、`003_AddNote.sql` を流す手順を伝えるメッセージを出す
- 表の列・索引・型は [database.md](database.md)。DB の種類で変わる所は、その文書の「SQL Server の場合」「SQLite の場合」

# ノートに出す他の機能の内容

ノートの画面に、他の機能 (最初は作業管理の作業報告)が作る、日ごとの内容を並べて出す仕組みの仕様。ノートの本体は [notes.md](notes.md) にある。

## 概要

- ノートで表示している日に、その日の作業報告を、ノートのカードの上に、1 枚の畳める枠で出す
  - 作業報告は、実績と予定
- 作業管理の機能がオフのときは、この内容は出せず、トグルも出ない
- 計算して出すだけで、ノートの表には保存しない
  - 保存すると、作業管理を直しても、ノートの文が古いままになるため
- 出す内容は、他の機能からも足せる形にする
  - 作業報告は、その 1 つ目
  - 機能が 10 個に増えても、ノートの画面とホストには、機能の名前を書き足さない

## 構成

- **契約**: 次を持つインターフェース `IDayContentSource` を、機能のどれにも属さない共通の Core に置く。
  - 識別: 内容のキー (`WorkReport`)・画面に出す名前・機能のキー。機能がオフの間は、その機能の内容を出さない。
  - 開始日の既定: 期間の終了日から、実績の開始日の既定を返す。作業報告は、作業報告の窓と同じで、直近の工数記入の日か完了にした日。無ければ前日。
  - 人の一覧: 期間 (開始日〜終了日)のうちに、内容がある人のユーザーの番号を返す。「全員」の枠の並びに使う。名前は、ノート側が、返された番号の人だけを引く。提供する機能ごとに、名前を引く処理を持たないため。
  - 内容: 期間と人を指定して、見出しと文を返す。期間は、終了日が報告日で、開始日が実績の開始日。その日だけの内容なら、開始日と終了日を同じにする。
  - 選択肢の宣言: 提供する側が、パネルに出す真偽の選択肢 (キー・表示名・既定値)を返す。作業報告なら、「実績に時間を出す」と「進捗度表示」。ノートは、中身を知らずに、チェックとして並べる。
  - 変更の通知: 内容が変わったことを知らせるイベント `Changed`。使う側は、見えている間だけ購読して、読み直す。通知しない提供元は、何もしない既定の実装のまま。どのスレッドから通知してもよく、使う側が画面のスレッドへ戻す。作業管理は、作業管理の変更の通知を受けて、これを出す。
  - 置き場は `src/DayContent/MmmTool.DayContent.Core` で、UI に依存せず、PC 版と Web 版の両方が使う。
  - 新設は、ユーザーが了承した。
  - 返すのは HTML ではなく、文字のデータ。ノートが、本文と同じ決まりでエスケープして出す。ページに入るのは、アプリが作ったタグだけ。詳細は [notes.md](notes.md) の「本文の表示」にある。
- **提供する側**: 作業管理が契約の実装を持ち、自分の登録 `Add<機能>()` に 1 行足して登録する。
  - 作業管理がオフなら、登録されない。
  - 実装は、画面を持たない `MmmTool.WorkItems.Core` に置く。PC 版と Web 版の両方が使う。
- **使う側**: ノートが、登録された実装を集めて、トグルと枠を作る。作業管理の名前は持たない。
  - 集める処理は `MmmTool.Notes.Core` に置き、PC 版 (`MmmTool.Notes`)と Web 版 (`MmmToolWeb.Notes`)が同じものを使う。同じ処理を、2 か所に書かないため。
  - `MmmTool.Notes.Core` が参照を足すのは、契約の `MmmTool.DayContent.Core` だけ。他の機能の Core は参照しない。
- 機能どうしは参照しない。ノートは契約だけを知る。
  - 作業管理を直接参照すると、作業管理を外したビルドでノートが作れなくなり、機能が増えるたびに参照が絡み合うため
- 作業報告の文は、`WorkReportBuilder` ([work-report.md](work-report.md))をそのまま使う。同じ文の形を、窓と枠で 2 つ作らない。

## 上のバーの「表示する内容」

- ノートの上のバー ([notes.md](notes.md) の「上のバー」)に、「表示する内容」のボタンを 1 つ足す。
  - 押すと、内容ごとのチェックが並ぶ枠が開く。
  - 提供する実装が 1 つも登録されていないときは、ボタンを出さない。
  - 内容を足しても、バーの部品は増えない。内容ごとのトグルを並べると、10 個で横にあふれるため。
- 作業報告のチェックの下に、次を並べる。作業報告がオフのときは見えない。

| 部品 | 内容 |
| --- | --- |
| 「全員の分も出す」 | DB モードだけのチェック。オフが自分だけで、ローカルモードは自分固定で、出さない。覚えず、毎回オフから始める |
| 実績の開始日 | `CalendarDatePicker`。既定は作業報告と同じ。ノートの日付を動かすと、既定に戻る |
| 「実績に時間を出す」「進捗度表示」 | 作業報告の窓と同じ設定を共有する |

- ノートが見えるようになったとき (ページを開く・トレイから出す)と、「表示する内容」を開くたびに、この PC の設定を読み直す。作業報告の窓が同じ設定を変えていたら、その値に合わせて、枠を作り直す。
  - 変更通知は入れない
    - 設定の保存先は変更通知を持たない
    - ノートが画面を作り直すのは見えたときだけで、そのとき読めば足りる
    - 見えていない間は、購読の後始末も要らない
- 報告日は選ばせず、ノートの上のバーの日付をそのまま使う
  - 日付の部品が 2 つあると、どちらが効くのか迷うため

## 枠の表示

- 位置は、ノートのカードの上。
- 枠の開閉は、ノートのカードと同じ。「タイトルだけ」がオンなら全部の枠を畳み、オフなら全部の枠を開く。枠ごとに押して、開閉もできる。
- 文は、作業報告のプレビューと同じ形で、等幅のフォントで出す ([work-report.md](work-report.md) の「画面 (仮)」)
- 「全員」を選んだときは、人ごとの枠を名前順に並べる。
  - 自分の枠を先頭に置き、あとは名前順にする。
  - 開閉は、上の「タイトルだけ」との連動に従う。自分の枠も同じ。
  - 「全員」を選んだら、全員分の中身を、最初からまとめて読む。畳んである枠も読む。
  - 人の一覧は、契約の「人の一覧」で読む。作業報告は、期間のうちに、実績か予定か日報メモがある人だけを返す。
  - ほかの人の日報メモも、その人の枠に出す。出し方は、自分の日報メモと同じで、[work-report.md](work-report.md) の「日報メモの出力」に従う。
- 実績も予定も無い日は、ノートの「この日のノートはありません」と同じ形で、「なし」を出す

## 読み

- 作業報告の読み ([work-report.md](work-report.md) の「読み (保存先)」)を、担当者を指定して呼べるようにする。
  - 「自分」は、ログインしている人。ローカルモードは `Id = 1`。
  - 「全員」で開いた枠は、その人の番号で、同じ問い合わせを使う。索引と、共通ヘッダーの列を使わない決まりは変わらない。
- ほかの人の作業と日報メモを読めるのは、DB モードだけ
- 表示する日・実績の開始日・チェックを変えたら、枠を作り直す
- ほかの人の更新は、ノートの定期の読み直し ([notes.md](notes.md) の「読み込みと反映」)で、全部の枠を読み直す

## Web 版

- ノートの API の答えに、同じ契約から集めた内容を添える。ブラウザ側は出すだけで、作業管理の名前を持たない。
- 出すかどうか・全員か・実績の開始日・選択肢は、ブラウザの画面の中だけで持つ。保存しない。ブラウザの画面を開き直すと、既定に戻る。
- 作業管理の実装を登録する、薄いプロジェクト `src/Plugins/MmmToolWeb.WorkItems` を新設する。新設は、ユーザーが了承した。
  - `MmmToolWeb.Notes` と同じ形で、サーバー本体に足すのは、登録の 1 行 (`AddWebFeature<…>()`)だけ
  - 作業管理を Web 版で動かさないときは、この 1 行を外す。ノートの「表示する内容」には、作業報告が出なくなる。
- 「全員」の枠は、API の 1 回の答えで、全員分をまとめて返す
- Web 用のログイン `MmmToolWeb` に、作業報告の読みに要る表の `SELECT` を足す ([web.md](web.md) の「DB の接続」)
  - 表は `WorkProject`・`WorkGroup`・`WorkItem`・`WorkRecord`・`WorkDayNote`・`CodeMaster`
  - `INSERT`・`UPDATE`・`DELETE` は付けない。読むだけ。
  - ほかの人の作業を読めるので、Web 版の見える範囲は、作業管理の画面と同じにする。違うときは、作る前にユーザーに聞く。

## 保存するもの

- 設定は、この PC の `Data/AppSettings.json` に置く。DB モードでも DB には置かない。

| 項目 | キー | 値 |
| --- | --- | --- |
| 作業報告の枠を出すか | `Notes.Sources.WorkReport.Enabled` | 真偽。既定は false |
| 「実績に時間を出す」「進捗度表示」 | `WorkItems.Report.ShowHours`・`WorkItems.Report.ShowProgress` | 作業報告の窓と共有する。詳細は [storage.md](storage.md) |

- 内容ごとのキーは、`Notes.Sources.<内容の名前>.Enabled` の形にそろえる
- 「自分 / 全員」と実績の開始日は、覚えない

# ツール

小さな便利ツールを並べるページ。サイドバーの Backlog の下 (設定を除く一番下)に出るページ 1 つ。`src/Plugins/MmmTool.Tools/`(Core 側は `src/Plugins/MmmTool.Tools.Core/`)。設定ページでオン・オフできる ([settings.md](settings.md))。初期状態はオン。

## データ
- 保存するデータは無い (`Data/` にファイルを作らない)。入力欄の内容も保存しない

## 画面
- ページの見出しは「ツール」。ツールごとにカードを 1 枚置く。今のカードは「URL を日本語に戻す」の 1 枚
- 「URL を日本語に戻す」のカードは、上から順に、説明文・入力欄 (見出し「貼り付け」)・結果欄 (見出し「結果」)を縦に並べる
  - 入力欄: 複数行。折り返して表示する。貼ったり打ったりするたびに、結果欄が更新される
  - 結果欄: 読み取り専用。選択してコピーできる。コピーのボタンは置かない
- 入力欄と結果欄は、URL が横に長いため、左右ではなく上下に並べる

## URL を日本語に戻す (`UrlDecoder`。Core)
- 文字列の中の `%XX` の並びを、UTF-8 として元の文字に戻す (`Uri.UnescapeDataString`)
- `%2F` や `%20` のような記号も戻す。結果は読むための文字列で、リンクとして開く用途ではない
- UTF-8 として読めない並び (Shift_JIS など)は、`%XX` のまま残る
- `+` は空白に直さない
- 複数行を貼っても、文字列全体に同じ処理をする

## 決定の理由

### 結果は読むためだけにし、`%2F` なども戻す
- 使う場面は、SharePoint の Excel のリンクから親フォルダを知ること。このリンクは、`?id=%2Fsites%2F…&parent=%2Fsites%2F…` のように、フォルダの区切りの `/` が `%2F` で書かれている。`%2F` を戻さないと、`/` を探せない
- 結果をリンクとして開く用途は、ユーザーが「読むだけで良くって」と決めた。ブラウザのアドレスバーのように、記号を残す形にしない

### 「ツール」ページに、道具を並べる入れ物として作る
- 最終形に近づく形: 汎用の小さな道具が増えても、サイドバーの項目は 1 つのままにして、ページの中にカードを足す
- 置き場所は、サイドバーの一番下 (Backlog の下。設定を除く)。ユーザーの決定 (2026-10-13)。登録の順は `AddFeaturePlugin<ToolsPlugin>(order: 7)`。並び替えは、設定の「機能」の一覧でできる
- トレイメニューの項目は足していない。トレイの項目を足すかは、ユーザーが決めていない
- 初期状態をオンにしたのは、特定の使い方に偏らない汎用のページで、保存先や接続の設定が要らないため

MmmTool
================================================================

開発作業を補助する、タスクトレイ常駐型のデスクトップアプリです。
AI エージェント (Claude Code・Kiro)の CLI 操作の補助、よく使うリンクの呼び出し、
リマインダーの通知などを 1 つのアプリにまとめています。

詳しい説明・ソースコード: https://github.com/Mimumumimu/MmmTool


■ 必要なもの
----------------------------------------------------------------

- Windows 10 (1809) 以上 (x64)
- .NET 10 Desktop Runtime (x64)
    https://dotnet.microsoft.com/download/dotnet/10.0
- Windows App Runtime 2.5 (x64)
    https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads
- Microsoft Edge WebView2 ランタイム (Windows 11 には標準で入っています)
    https://developer.microsoft.com/microsoft-edge/webview2/
- PowerShell 7 (任意。入っていれば、ターミナルで優先して使います)
- WSL (任意。CLI補助で WSL の Claude Code・Kiro を使うとき。Claude Code の会話履歴の削除には
  WSL の中の Python 3 が要ります。Ubuntu には標準で入っています)

ランタイムは同梱していません。.NET と Windows App Runtime は、入っていなければ
MmmTool.exe を起動したときに案内のダイアログが出るので、そこからダウンロードして
インストールできます。


■ 起動と終了
----------------------------------------------------------------

- MmmTool フォルダの中の MmmTool.exe を開きます。ウィンドウは出ず、タスクトレイにアイコンが出ます。
- トレイアイコンを左クリックすると、メインウィンドウが開きます。
- ウィンドウの × で閉じても、トレイに残ります。
- 終了するときは、トレイアイコンを右クリックして「終了」を選びます。
- 同じ MmmTool.exe は 2 つ同時に起動できません。


■ 置き場所
----------------------------------------------------------------

この README.txt と同じ場所にある MmmTool フォルダが、アプリ本体です。
インストールは不要で、展開したまま使えます。MmmTool フォルダは、好きな場所
(例: D:\Tools\MmmTool)へ移して使うこともできます。版が変わってもフォルダ名は MmmTool のままなので、
ショートカットなどはそのまま使えます。

- 自分だけが書き込めるフォルダに置いてください。
  他の人が書き込めるフォルダに置くと、Data フォルダの定型コマンドやリンクを書き換えられ、
  意図しないコマンドを実行されるおそれがあります。
- Lib フォルダの中身を動かしたり、EXE の横へ移したりしないでください (起動できなくなります)。


■ データの保存場所
----------------------------------------------------------------

アプリのデータは、すべて EXE と同じ場所の Data フォルダに保存されます。

  Data\*.json      設定・リンク・定型コマンド・リマインダーなど
  Data\Logs\       エラーのログ (自動では消えません)
  Data\WebView2\   ターミナルの画面のキャッシュ (消しても作り直されます)

- JSON を手で直すときは、アプリを終了してから行ってください。
- CLI補助で貼り付けた画像だけは、%TEMP%\MmmTool\ に一時保存されます (タブを閉じるとき・終了時に削除)。
  CLI補助を WSL で使うときは、WSL の /tmp/MmmTool/ に置きます (終了時には削除せず、
  WSL の再起動で消えるのに任せます)。
  ドラッグ＆ドロップなどで添付したファイルはコピーせず、元のファイルのパスを渡します。
- Backlog の API キーだけは、Data フォルダーではなく、Windows の資格情報マネージャー
  (「Windows 資格情報」の汎用資格情報「MmmTool.Backlog」)に保存されます。削除するときは、
  資格情報マネージャーから消してください。


■ 新しい版への入れ替え
----------------------------------------------------------------

1. トレイの「終了」で MmmTool を終了します。
2. 新しい版の MmmTool フォルダの中身を、今使っている MmmTool フォルダに上書きコピーします。
   Data フォルダは新しい版に含まれていないので、そのまま残ります
  (新しい版のフォルダに Data があるときは、それはコピーしないでください)。


■ アンインストール
----------------------------------------------------------------

MmmTool を終了してから、MmmTool フォルダを丸ごと削除します。
%TEMP%\MmmTool\ が残っていたら、それも削除してください。
Backlog の API キーを登録していたときは、Windows の資格情報マネージャー (「Windows 資格情報」の
汎用資格情報「MmmTool.Backlog」)から、その項目も削除してください。


■ 変更履歴
----------------------------------------------------------------

未リリース
- 修正: リマインダー入力画面で、ボタンの下の余白が空きすぎる不具合を直した
- 修正: ダークモードで、作業ディレクトリ変更・CLI補助の初期設定・確認・ファイルの競合のダイアログが、背景と文字でテーマが食い違い、読みにくくなる不具合を直した
- 追加: CLI補助のターミナルをタブで複数開けるようにした (1 タブ = 1 つの CLI。「＋」で作業ディレクトリを選んで開き、「×」で確認してから閉じる。タブ名は作業フォルダ名。同じフォルダのタブは開けない。入力欄と添付はタブごと、定型コマンドと送信履歴は共通)
- 追加: CLI補助の定型コマンドに、シェルの「履歴から選んで再開」を足した (Claude Code は `claude --resume`、Kiro は `kiro-cli chat --resume-picker`。会話の一覧から選んで再開する。すでに使っている場合は、「定型コマンドを初期化…」で反映される)
- 変更: リマインダーの画面の位置と大きさを覚えて、次に開くとき同じ場所に出すようにした (初めて開くときは、メインモニターの右下)
- 追加: リマインダーの通知の読み上げ (入力画面の「通知を読み上げる」をオンにしたリマインダーを、通知のたびに「件名。備考。」と日本語の音声で読む。Windows 標準の音声合成を使うので、日本語の音声が入っていない PC では読まれない)
- 追加: 設定ページに「読み上げの声・速さ」を足した (Windows の音声設定を開くリンク。読み上げの声と速さは Windows の設定に従う)
- 変更: リマインダーの通知に、備考も「件名 (備考)」と出すようにした
- 変更: CLI補助の Kiro の「会話履歴の削除」を、Kiro の一覧 (Ctrl+D)を開く方式から、Claude Code と同じ矢印キーで選ぶ画面に変えた (全作業フォルダの履歴をまとめて選べる。Kiro の削除は戻せない。すでに使っている場合は、「定型コマンドを初期化…」で反映される)
- 追加: Backlog (サイドバーのクリップボード転送の下。Backlog の共有ファイルの一覧を取得して、ファイルをダウンロードする。API キーは設定ページで登録し、Windows の資格情報マネージャーに保存する。設定でオン・オフできる)
- 追加: クリップボード転送 (サイドバーの CLI補助の下。ファイルをクリップボードに載せて別の PC へ渡し、クリップボードから保存する。送信はドロップか「ファイルを選択」、受信は「クリップボードから保存」。複数のファイル・同じ名前のファイルの置き換え / スキップの確認に対応。1 ファイル 160 MB まで)
- 追加: 設定で機能をオン・オフできるようにした (今は CLI補助・クリップボード転送・Backlog。オフにすると、サイドバー・トレイメニューから消え、すぐ反映される。ターミナルが動いている間にオフにすると確認が出る)
- 変更: CLI補助でドラッグ＆ドロップ・貼り付けしたファイルを一時フォルダーへコピーせず、元のファイルのパスを渡すようにした (× で添付から外しても、元のファイルは消えない)
- 変更: CLI補助の添付の指示文に「ファイルを変更するのは、指示で求められたときだけ」を加えた
- 変更: CLI補助の添付の一時保存先を %TEMP%\MmmTool\ の直下にして、送るパスを短くした
- 修正: CLI補助で、下の入力欄からターミナルをクリックすると、日本語入力がオンなのに英字が入ってしまうのを直した
- 修正: CLI補助で本文を書かずにファイルだけを送ったとき、指示文が「上記の指示に関連して」で始まっていた
- 追加: CLI補助を WSL でも動かせるようにした (初めて開いたときに Windows / WSL を選ぶ。WSL では作業ディレクトリ・添付のパスを /mnt/d/... の形にして渡す。貼り付けた画像は WSL の /tmp に置く)
- 追加: CLI補助で Kiro を使えるようにした (初めて開いたときに、使うツール (Claude Code / Kiro。両方も可)を選ぶ)
- 追加: CLI補助の「定型コマンドを初期化…」 (定型コマンドを既定の内容に作り直し、使うツールと Windows / WSL を選び直す)
- 追加: WSL 版の補助スクリプト「会話履歴の削除」 (Python 3。操作は Windows 版と同じ。Linux のごみ箱 ~/.local/share/Trash へ移す)

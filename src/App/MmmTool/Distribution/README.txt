MmmTool
================================================================

開発作業を補助する、タスクトレイ常駐型のデスクトップアプリです。
開発で使う機能を 1 つにまとめています。

■ 最初に: Data フォルダを上書きしないでください
----------------------------------------------------------------

入力したデータはすべて Data フォルダに保存されます。
Data フォルダは、MmmTool.exe を起動したときに、MmmTool.exe と同じフォルダに作られます。
ダウンロードしたばかりの状態では、まだありません。
起動したフォルダごとに、別々の Data ができます。

MmmTool 一式をコピーするとき、コピー先に Data フォルダがあると、
Windows が「置き換えますか」といった確認を出します。
Data フォルダが置き換わると、元のデータは消えて戻せません。

別の場所へ移すときや新しいバージョンに替えるときは、
これまで使ってきた Data フォルダを先にバックアップしてください。
Data フォルダを丸ごと別の場所にコピーしておけば、上書きしてしまっても元に戻せます。


■ 機能一覧
----------------------------------------------------------------

左のメニュー (サイドバー)に並ぶ機能です。使い方は下の「操作説明」を見てください。

- CLI補助 ........... アプリ内のターミナルで、Claude Code・Kiro への指示や定型コマンドの送信を補助
- 作業管理 ........... 案件・グループ・作業の管理と、日ごとの実績・日報メモの記録、作業報告の作成
- リマインダー ....... 日付・曜日を指定した通知と、読み上げ
- リンク ............. URL・フォルダ・ファイルの登録と、トレイメニューからの呼び出し
- クリップボード転送 .. ファイルをクリップボード経由で別の PC へ受け渡し
- Backlog ........... Backlog の共有ファイルの一覧取得とダウンロード
- ツール ............. 小さな便利ツール (URL の文字コードを日本語に戻す)

初期状態では、CLI補助・作業管理・クリップボード転送・Backlog はオフです
(サイドバーに出ません)。使うときは、設定の「機能」でオンにしてください (操作説明.html の「設定」を参照)。
リンクとリマインダーは、オフにできません。


■ 動作環境
----------------------------------------------------------------

- Windows 11 (x64)
- PowerShell 7 (任意。入っていれば、ターミナルで優先して使います)
- WSL (任意。CLI補助で WSL の Claude Code・Kiro を使うとき。Claude Code の会話履歴の削除には
  WSL の中の Python 3 が要ります。Ubuntu には標準で入っています)

ランタイムは同梱していません。入っていないときは、MmmTool.exe を起動すると
案内が出るので、そこからインストールできます。
先に入れておくときは、次のページから入手してください。

- .NET 10 Desktop Runtime (x64)
    https://dotnet.microsoft.com/download/dotnet/10.0
- Windows App Runtime 2.5 (x64)
    https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads
- Microsoft Edge WebView2 ランタイム (Windows 11 には標準で入っています)
    https://developer.microsoft.com/microsoft-edge/webview2/


■ 置き場所
----------------------------------------------------------------

この README.txt と同じフォルダにある MmmTool.exe が、アプリ本体です。
インストールは不要で、展開したまま使えます。フォルダは好きな場所
(例: D:\Tools\MmmTool)に移せますし、名前も自由に変えられます。

- 自分だけが書き込めるフォルダに置いてください。
  他の人が書き込めるフォルダに置くと、Data フォルダの定型コマンドやリンクを書き換えられ、
  意図しないコマンドを実行されるおそれがあります。
- Lib フォルダの中身を動かしたり、MmmTool.exe と同じフォルダへ移したりしないでください (起動できなくなります)。


■ 起動と終了
----------------------------------------------------------------

- MmmTool.exe を開きます。ウィンドウは出ず、タスクトレイにアイコンが出ます。
  (設定の「起動時にメイン画面を開く」をオンにすると、起動時にメインウィンドウも開きます)
- トレイアイコンを左クリックすると、メインウィンドウが開きます。
- ウィンドウの × で閉じても、トレイに残ります。
- 終了するときは、トレイアイコンを右クリックして「終了」を選びます。
- 同じ MmmTool.exe は 2 つ同時に起動できません。
- 初めて起動したときは、データの保存先を選ぶ画面が出ます。通常は「ローカル」を選びます。
  「サーバー」は、複数の PC でデータを共有するときの選択肢で、サーバー側の準備が必要です。

■ データの保存場所
----------------------------------------------------------------

アプリのデータは、MmmTool.exe と同じフォルダの Data フォルダに保存されます。

  Data\CliCommands.json        CLI補助の定型コマンド
  Data\CliSettings.json        CLI補助の最後の作業ディレクトリ・履歴・開いているタブ
  Data\CliQuickMessages.json   CLI補助のよく使う文
  Data\Links.json              リンク
  Data\Reminders.json          リマインダー
  Data\ReminderStates.json     リマインダーの対応状態
  Data\MmmTool.db              作業管理 (SQLite)
  Data\AppSettings.json        設定・ウィンドウの位置など
  Data\Logs\                   エラーのログ (自動では消えません)
  Data\WebView2\               ターミナルの画面のキャッシュ (消しても作り直されます)

- 作業管理のデータ (Data\MmmTool.db)は、起動したときに、必要なら自動で新しい形に直ります。
- JSON を手で直すときは、アプリを終了してから行ってください。
- JSON として読めない (壊れた)ファイルは、名前を変えて同じフォルダに退避し、新しく作り直します。
  退避したファイルは自動では消えません。
- CLI補助で貼り付けた画像だけは、%TEMP%\MmmTool\ に一時保存されます (タブを閉じるとき・終了時に削除)。
  CLI補助を WSL で使うときは、WSL の /tmp/MmmTool/ に置きます (終了時には削除せず、
  WSL の再起動で消えるのに任せます)。
  ドラッグ＆ドロップなどで添付したファイルはコピーせず、元のファイルのパスを渡します。
- Backlog の API キーと、サーバー保存を使うときの接続情報だけは、Data フォルダではなく、
  Windows の資格情報マネージャー (「Windows 資格情報」の汎用資格情報のうち、名前が
  「MmmTool」で始まる項目)に保存されます。削除するときは、資格情報マネージャーから消してください。


■ アンインストール
----------------------------------------------------------------

MmmTool のフォルダを、丸ごと削除してください。
%TEMP%\MmmTool\ が残っていたら、それも削除してください。
Backlog の API キーやサーバーの接続情報を登録していたときは、Windows の資格情報マネージャー
(「Windows 資格情報」の汎用資格情報のうち、名前が「MmmTool」で始まる項目)から、
その項目も削除してください。


■ 変更履歴
----------------------------------------------------------------

未リリース

追加
[メッセージ] 新機能 (サーバーモードのみ): 宛先を選んで、短いメッセージを送る依頼を出せます
　・サイドバーの「メッセージ」のページと、トレイメニューの「メッセージ送信」から開く
　・宛先は、自分以外のユーザーの送信先も選択可能。前回送った宛先を覚える
　・タイトルは任意 (100 文字まで)、本文は 1,000 文字まで
[作業管理]
　・状態と進捗度や実績が食い違う入力をしたとき、入力したセルの下に警告を数秒だけ表示 (入力は止めません)
　・入力日が作業の開始日より前のとき、実績 (日)か備考 (日)を入力すると、入力したセルの下に警告を数秒だけ表示 (入力は止めません)
　・完了していない作業の期限日が入力日より前のとき、期限日を赤い文字と警告のアイコンで表示 (アイコンに触れると、過ぎた日数を表示)
[リンク]
　・編集画面で、パスが URL のとき、種類の説明の右側に URL を表示 (日本語のエンコードは読める形に直して表示。選んでコピーできます)
[設定]
　・「送信先」を追加 (サーバーモードのみ)。送信先の登録画面を、設定ページから開けます

修正
[作業管理]
　・完了日が入力日より前の作業を、行の背景を灰色にして、入力・移動・削除ができないように変更 (リンクを開くことと備考を読むことはできます)。直したいときは入力日を完了日に戻します
　・「表示する案件」で、最初は表示している案件だけを一覧に出すよう変更 (完了した案件も出るので、そのまま外せます)。非表示の案件は、「非表示の案件も表示」にチェックを入れると出ます。「進行中のみ」は廃止
　・日付が空の開始日・終了日のカレンダーを、入力日の月で開くよう変更 (終了日は、開始日があれば開始日の月)
　・「リンクを編集…」を、行のどこを右クリックしても選べるよう変更 (「リンクをクリア」は、これまで通り「リンク」のセルを右クリックしたときだけ)
　・セルを右クリックしたときも、左クリックと同じように、そのセルを選んで枠を出すよう変更 (入力は始まりません)
　・選んだセルの枠が、選んだ行の上下の紫の線より前に出るよう調整 (枠の下側は行の下端まで伸ばしました)

不具合の修正
[作業管理]
　・入力できない (完了して日がたった)行の「備考 (日)」だけ、背景の色が違っていたのを修正
　[作業報告]
　　・出力で、備考の行頭の字下げ (全角スペースなど)が消える不具合を修正
[全般]
　・画面の位置と大きさを覚えて復元するとき、倍率 (100% や 150% など)が主モニターと違うモニターに置いた画面の大きさがずれる不具合を修正 (通知ウィンドウも同様)

追加
[作業管理] 新機能 (サイドバーに追加): 日々の作業を管理し、実績を報告用に出力
　・案件・グループ・作業を木構造で管理
　・日ごとの実績と備考を、表のセルに直接入力して記録
　・グループの日付・予定時間・実績・進捗度は、下の作業から自動で計算
　・案件ごとに表示・非表示を切り替え、表示する列を選択

　・送る側: ファイルをドロップまたは選択 (複数可)
　・受け取る側: 別の PC の MmmTool で、クリップボードから保存
　・同じ名前のファイルがあるときは、置き換え・スキップ・ファイルごとに選択
[Backlog] 新機能 (サイドバーに追加): 共有ファイルの一覧取得とダウンロード
　・設定で API キーを登録し、連携用パス (URL)から一覧を取得
[サーバー保存] 新機能 (複数の PC でデータを共有できます)
　・リマインダーと作業管理のデータを共有
　・起動時にログインが必要。作業管理では、作業に担当者を付けられる
[CLI補助]
　・タブ機能を追加
　　・フォルダごとに 1 タブ。ドラッグで並べ替え
　　・アプリを終了しても、次の起動でタブを復元 (CLI は自動では起動しない)
　・Kiro と WSL に対応
　　・初回に、使うツール (Claude Code / Kiro)と動かす環境 (Windows / WSL)を選択
　・送信欄に「よく使う文」を追加
　　・送信欄が空のとき、ボタンで並び、押すと送信欄に入る。追加・編集・並べ替えも可能
　・定型コマンドに「履歴から選んで再開」を追加
　[会話履歴の削除]
　　・Kiro と WSL に対応
[リマインダー]
　・通知の読み上げを追加
　　・入力画面の「通知を読み上げる」をオンにすると、件名と備考を音声で読む
　・サイドバーに一覧を追加
　　・全件を表示。右クリックで編集・コピーして新規追加・削除
　・「コピーして新規追加」を追加
　・通知に備考を表示
　・削除時に確認ダイアログを表示
　・画面の位置と大きさを保存
[設定]

　・「音声機器を起こしておく」を追加

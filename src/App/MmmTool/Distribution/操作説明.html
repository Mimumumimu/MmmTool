はじめに

起動すると、タスクトレイにアイコンが出ます。

  • アイコンを左クリック: メインウィンドウを開く
  • アイコンを右クリック: 「リンク」「リマインダー」などのメニュー。「終了」で完全に終了。
  • ウィンドウを × で閉じても、トレイに残る。
  • サイドバーで開いたページは、タイトルバーの左の 戻る と 進む で、順にたどれる。Alt+← と Alt+→ でも同じ。
機能のオン・オフ初期状態では、CLI補助・作業管理・クリップボード転送・Backlog は、サイドバーに出ません。使う機能は、設定 の「機能」でオンにします。

CLI補助

アプリの中でターミナルを動かし、Claude Code・Kiro への指示や、よく使うコマンドの送信を助けます。

操作手順

  1. 初めて開いたとき、使うツール (Claude Code / Kiro)と、動かす環境 (Windows / WSL)を選ぶ。
  2. タブの ＋ で、作業するフォルダを選んで、タブを開く。
  3. 左の定型コマンド (例: Claude Code の「起動」)をクリックして、CLI を起動する。
  4. 下の送信欄に指示を書いて、Ctrl+Enter で送信する。

補足

  • 添付: 画像は Ctrl+V、ファイルはドラッグ＆ドロップ。ファイルはコピーせず、元の場所のパスを渡します。フォルダーを入力欄にドロップすると、そのパスが入力欄に入ります。
  • よく使う文: 送信欄が空のとき、ボタンで並びます。押すと送信欄に入ります。鉛筆ボタンで追加・編集・並べ替え。
  • タブ: フォルダごとに 1 タブ。ドラッグで並べ替え。アプリを終了しても次の起動で戻ります。CLI は自動では起動しません。
  • 会話履歴の削除: 定型コマンドから、Claude Code・Kiro の古い会話を選んで消せます。
  • 定型コマンドの作り直し: 左の一覧の右上の ⋯ →「定型コマンドを初期化…」
ヒント定型コマンドは Data\CliCommands.json でも直せます。アプリを終了してから直してください。

ノート

期間を決めて書いたノートが、その日になると、1 枚の画面に並びます。連絡事項にも、書き足していく手順やメモにも使えます。

操作手順

  1. サイドバーの「ノート」で、新規 を押す。
  2. タイトルと本文を書き、開始日と終了日を決めて、OK を押す。終了日は、空のままだと無期限になる。
  3. 前の日・次の日・日付の選択で、日を変えて読む。その日に有効なノートが、重要度の高い順に並ぶ。
  4. カードの右上の 編集・削除 で、直したり削除したりする。カードの上で右クリックしても、同じ操作ができます。

補足

  • 書式: 本文は、書いたとおりに表示されます。文字を選んで右クリックすると、太字・斜体・下線・取消線・色を付けられます。リンクを追加 では、リンク名と、URL またはファイル・フォルダーのパスを入れます。
  • ファイルのドロップ: 本文にファイルやフォルダーをドロップすると、そのリンクが入ります。
  • URL: https:// で始まる文字は、自動でリンクになります。
  • HTML のタグ: 知っていれば、<b> や <a href="…"> などを、直接書けます。使えるタグは、太字・斜体・下線・取消線・改行・箇条書き・色・リンクだけです。
  • タイトルだけ: 上のバーのスイッチで、全部のカードを、タイトルだけの表示にできます。カードを押すと、そのカードだけが開きます。
  • 削除したもの: 削除したものも表示 を入れると、削除済みのノートも出ます。復元 で、いつでも戻せます。
  • 作業報告を出す: 作業管理がオンのとき、表示する内容 で「作業報告」を入れると、その日の作業報告 (実績と予定)が、ノートの上に出ます。実績の開始日と、「進捗度表示」「実績に時間を出す」も、ここで選べます。選びは、作業管理の作業報告の窓と共通です。
  • 全員の分: サーバー保存では、全員の分も出す を入れると、ほかの人の作業報告と日報メモも、人ごとの枠で並びます。自分の枠が先頭です。
  • 重要度: 「最高」は赤、「高」は橙の帯が付きます。同じ重要度の中は、更新が新しい順です。
  • 実施日: 入力で 実施日 を決めると、その日のカードが紫の帯と枠で目立ち、ほかのカードより上に出ます。タイトルだけの表示のときも、目立ちます。クリア で、いつでも未設定に戻せます。
    • 実施日が、開始日から終了日の外のときは、開始日か終了日が動いて合わせます。終了日が空のときは、終了日は動きません。
    • 開始日や終了日を動かして、実施日が期間の外になったときは、赤い警告が出て、保存できません。どちらかを直してください。
    • 実施日の当日は、アプリを起動したときと、日付が変わったときに、通知が出ます。通知を押すと、ノートのページが開きます。ノートをオフにしているときは、出ません。
  • 今日更新: 今日更新したノートには、「今日更新」の印が付きます。
ヒント終了日を空にしたノートは、毎日出ます。不要になったら、終了日を入れて終わらせます。

作業管理

案件・グループ・作業を木構造で管理し、日ごとの実績と備考を、表のセルに直接入力して残します。

操作手順

  1. ページ見出し右の 案件の管理 で、案件を作る。
  2. 案件やグループの行を右クリックして、グループ・作業を追加する。
  3. セルを左クリックして入力し、Enter で保存する。薄い緑の列が、毎日入れる列です。
  4. 入力日 (左上の ◀ ▶ 今日)を動かして、日ごとの実績と備考を残す。
  5. 打ち合わせなど、作業に結びつかないことは、表の下の入力欄に日報メモとして書く。入力欄から外れると保存される。

補足

  • グループの数字は自動: 日付・予定時間・実績・進捗度は、下の作業から計算されます。
  • 実績の合計: 上のバーの入力日の隣に、入力日の実績の合計が出ます。表示している案件の分を数え、自分の担当だけ を入れると、自分が担当の作業の分だけになります。過去の完了 で隠した作業の分も含みます。
  • 食い違いの警告: 状態を「完了」にしたのに進捗度が 100% でないとき、状態が「未対応」の作業に進捗度や実績を入れたとき、入力日が開始日より前の作業に実績や備考 (日)を入れたときは、入力したセルの下に警告が数秒だけ出て消えます。入力は止まりません。
  • 完了した作業: 完了日が入力日より前の作業は、行の背景が灰色になり、入力・移動・削除ができません。リンクを開くことと、備考を読むことはできます。直したいときは、入力日を完了日に戻します。
  • 過去の完了の表示: 上のバーの 過去の完了 で、完了日が入力日より前の作業の見え方を選びます。グループのみ表示 (最初の状態)は作業の行を隠し、グループは残します。非表示 は、すべて完了したグループも隠します。表示 は隠さず、すべて完了したグループは畳んだ 1 行で出ます。入力日に完了した作業は、グループのみ表示でも非表示でも出ます。選びは保存せず、起動のたびにグループのみ表示に戻ります。
  • 期限切れ: 完了していない作業で、期限日が入力日より前のものは、期限日が赤い文字になり、警告のアイコンが付きます。アイコンに触れると、過ぎた日数が出ます。入力日を過去に戻すと、その日に遅れていた作業が出ます。
  • リンク: 「リンク」の列のセルを左クリックで開く。行のどこかを右クリックして「リンクを編集…」で入れる・直す。空にするときは、「リンク」のセルを右クリックして「リンクをクリア」。
  • 日付: 開始日・期限日はカレンダーで選ぶ。右クリックの「日付をクリア」で空に戻す。
  • 作業報告に含めない: 定例の会議のように、報告しない作業は、行を右クリックして 作業報告に含めない にチェックを入れます。名前の右端にアイコンが付き、作業報告の実績にも予定にも出なくなります。外すときは、もう一度選びます。
  • 見え方: 表示列 で列を (列名を右クリックして 列を非表示 でも隠せます)、表示する案件 で案件を、出し入れできます。案件は、表示中の一覧のチェックを外して非表示にし、非表示の案件も表示 にチェックを入れて戻します。

作業報告

作業報告 を押すと、作業から、実績と予定を、貼り付けやすいテキストにしてコピーします。

  • 報告日: 開いたときは、作業管理で選んでいる入力日になります。
  • 実績: 実績の開始日から報告日の前日までに、工数を入れた作業と、完了にした作業。
  • 予定: 状態が「作業予定」「作業中」の作業
  • 各作業の行には、状態と進捗度が付きます。進捗度表示 で、出す・出さないを選べます。実績に時間を出す をオンにすると、実績の行に工数の合計が [3.5h] の形で付きます。
  • 日報メモ: 報告日の分が、「予定」の末尾に、書いたとおり出ます。「実績」には出ません。

スケジュール

サイドバーの 作業管理 の下にある スケジュール で、作業の予定と実績を、日付を横に並べて見ます。見るだけで、ここから入力はできません。

  • 予定: 開始日から期限日までの太い棒です。開始日だけの作業は、開始日に印と、右へ伸びる点線で、期限だけの作業は、期限日に印と、左へ伸びる点線で出ます。案件とグループは、下の作業をまとめた期間です。
  • 実績: 工数を入れた最初の日から最後の日までの、細い 1 本の棒です。単位が 日 のときは、工数を入れた日の位置に、時間が数字で入ります。案件とグループは、下の作業の合計です。
  • 単位と動かし方: 日・週・月 から選びます。開くたびに「日」になります。単位を変えても、見ている範囲の中央の日付は保たれます。全体が見えている 月 から切り替えたときは、今日が中央に来ます。横のスクロールで動かし、今日 を押すと、今日が見える位置に戻ります。
  • 休みの日: 土曜の列は薄い青、日曜と祝日の列は薄い赤の背景になります。月の単位は塗りません。祝日は、Assets\Holidays\syukujitsu.csv で判定します。内閣府が公開している「国民の祝日」の一覧です。一覧にない先の年の祝日は出ないので、新しい年の分は、内閣府の最新の一覧に置き換えてください。次に起動したときから使います。
  • 期限切れ: 完了していない作業で、期限日が今日より前のものは、予定の棒に赤い枠、進捗の右に警告のアイコンが付きます。アイコンに触れると、過ぎた日数が出ます。
  • 見え方: 表示する案件 と 自分の担当だけ は、作業管理と同じ設定です。完了 は、表示・グループのみ表示・非表示 から選びます。作業管理の 過去の完了 とは別の設定で、開くたびに「非表示」になります。非表示 では、完了した作業と、すべて完了したグループを隠し、グループのみ表示 では、作業だけを隠します。今日完了した作業も隠れます。案件の行は隠れず、案件とグループの棒と合計は、隠した作業を含みます。

リマインダー

日付や曜日を決めて、時刻になったら通知します。

操作手順

  1. トレイアイコンを右クリックして「リマインダー」を開き、新規追加 を押す。
  2. 件名と、日付か曜日、時刻を入れて、OK を押す。曜日を選ばなければ毎日になる。
  3. 時刻になると、画面の隅に通知が出る。
  4. 通知の本文をクリックすると、メイン画面が開く。未 / スヌーズ / 完了 で対応状態を切り替える。

補足

  • 再通知: 未対応は毎分、スヌーズは設定した間隔 (既定 15 分)で、繰り返し通知します。
  • 読み上げ: 入力画面の「通知を読み上げる」をオンにすると、件名と備考を音声で読みます。
  • 一覧: サイドバーの「リマインダー」で全件を見られます。行の右クリックで、編集・コピーして新規追加・削除。
  • リンク: リンクを入れておくと、件名のクリックで開きます。
  • まとめて追加: まとめて追加 を押し、左の表で会議の時刻にチェックを入れると、右の一覧に会議が並びます。件名には、最初から「会議」が入っています。リンクは、空のままでも登録できます。何分前に通知 を選ぶと、件名の後ろに開始時刻が付きます。例は 定例会議 (10:00 開始) です。通知を読み上げる と 送信先 も選べます。選んだ内容は、次に開いたときの初期値になります。
注意通知の本文をクリックして閉じると、時刻を過ぎて未対応のものは、スヌーズに進みます。気づいたとみなすためです。× で閉じたときは進みません。

リンク

URL・フォルダ・ファイル・実行ファイルを登録して、トレイのメニューから呼び出します。

操作手順

  1. サイドバーの「リンク」で、リンクを追加 を押し、パスや URL を入れる。参照 で選ぶこともできる。
  2. Ctrl+S で保存する
  3. トレイアイコンを右クリックして「リンク」から開く

補足

  • フォルダーを追加 と 区切り線を追加 で、階層に整理できます。
  • ドラッグ＆ドロップで、並べ替えとフォルダへの移動ができます。
  • 「開いて確かめる」で、登録したリンクが開けるか確かめられます。
  • %USERPROFILE% などの環境変数も使えます
  • パスが URL のときは、種類の説明の右に URL が出ます。日本語の部分は読める形になっていて、選んでコピーできます。

クリップボード転送

ファイルをクリップボード経由で、別の PC へ渡します。リモートデスクトップなど、クリップボードを共有できる環境用です。

送る側ファイルを「送信」の枠にドロップするか、ファイルを選択 を押す。複数可、1 ファイル 160 MB まで
受け取る側別の PC でも MmmTool を開き、クリップボードから保存 を押して、保存先を選ぶ
ヒント同じ名前のファイルがあるときは、「置き換える」「スキップする」「ファイルごとに決める」から選べます。

Backlog

Backlog の共有ファイルの一覧を取り、ダウンロードします。

操作手順

  1. 設定の「Backlog の API キー」に、Backlog の個人設定で発行した API キーを入れる。
  2. 「連携用パス (URL)」に、Backlog のファイル画面の URL を貼り、一覧取得 を押す。
  3. 行の ダウンロード で、保存先を選んで保存する。
注意ファイルの追加・削除は、Backlog の仕様で、ここからはできません。ブラウザで開く で Backlog の画面を開いて行います。

ツール

小さな便利ツールを並べたページです。

URL を日本語に戻す

  1. 「貼り付け」の欄に、文字コード (%E6%97%A5… のような並び)になった URL を貼る。
  2. 「結果」の欄に、日本語に戻った文字列が出る。選択してコピーできる。
注意結果は読むための文字列です。/ や & も戻すので、そのままブラウザで開くリンクとしては使えません。

設定

サイドバー下部の「設定」です。値を変えると、すぐ保存されます。

機能使わない機能のオン・オフ。リンクとリマインダーはオフにできません。行のドラッグで、サイドバーの並び順も変えられます
起動時にメイン画面を開くオンにすると、起動時にメインウィンドウも開きます
音声機器を起こしておく無音を流し続けて、光デジタルなどの機器が休止して、読み上げの頭が切れるのを防ぎます
スヌーズ間隔リマインダーの再通知の間隔 (5〜999 分)
保存先ローカル / サーバー。変えて保存すると、アプリの再起動で反映されます
読み上げの音量0〜100%。「試し聞き」で確かめられます

サーバー保存 複数の PC で共有

保存先をサーバーにすると、リマインダー・作業管理・ノートのデータを、複数の PC で共有できます。

  • サーバー側の準備が必要です。使いたいときは、管理者に相談してください。
  • 設定の「保存先」で切り替えます。切り替えたあと、アプリの再起動が必要です。
  • サーバーを使うときは、起動時にログインが必要です。作業管理では、作業に担当者を付けられます。
  • サイドバーの「メッセージ」(またはトレイメニューの「メッセージ送信」)で、宛先を選んで短いメッセージを送れます。届くまで、最大で約 5 秒かかります。
  • 作業管理・スケジュール・ノートでは、ほかの人の更新が約 1 分ごとに自動で反映されます。すぐ見たいときは、ページ右上の更新ボタン (回転する矢印のアイコン)を押します。
  • ノートは、複数の人で共有できます。ノートごとに、全員 に見せるか、自分だけ にするかを選べます。ほかの人が書いたノートも、直したり削除したりできます。「自分だけ」のノートは、書いた人にしか見えません。
